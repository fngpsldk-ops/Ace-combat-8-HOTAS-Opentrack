# AC8 HOTAS ブリッジ（ヘッドトラッキング対応）v1.02

ACE COMBAT 8 で **HOTAS（フライトスティック・スロットル）** と **OpenTrack ヘッドトラッキング** を使えるようにするツールです。

AC8 は Xbox パッドしか正しく認識しません。このツールはスティック・スロットルの入力を **仮想 Xbox 360 パッド** に変換します。
ゲームファイルの改変やゲームへのコード注入は行いません。

```
スティック + スロットル ─┐
                         ├→ ブリッジ → 仮想 Xbox 360 パッド → AC8
OpenTrack ───────────────┘   （ヘッドトラッキング → 右スティック = カメラ）
```

- DirectInput 方式のスティック／スロットル／ペダルならメーカーを問わず使用可能（VKB、Virpil、Thrustmaster、Logitech など）
- スロットルが無くても使用可能（加速／減速をボタンに割り当て）
- 設定画面：한국어 / English / 日本語

## 必要なもの

| 項目 | 必須 | 備考 |
|---|---|---|
| Windows 10/11 | 必須 | |
| 64ビット Python 3.10～3.14 | 必須 | インストール時に **「Add python.exe to PATH」にチェック** |
| ViGEmBus ドライバー | 必須 | `0_Install.bat` を実行するとセットアップ画面が表示されます |
| OpenTrack | 任意 | ヘッドトラッキングを使う場合のみ |
| HidHide | デバイスによる | ブリッジを閉じてもゲームがスティックに反応する場合に必要（下記「実デバイスをゲームから隠す」参照） |

**Python の互換性**
- 動作確認済み：Python 3.10、3.14（python.org 公式の64ビット版インストーラー）
- 3.11～3.13、3.15：必要なパッケージが対応しているため動作する見込みです（未確認）。
- 非対応：
  - Python 3.9 以前
  - 32ビット版 Python
  - ARM64 版 Windows 用 Python（仮想パッドのライブラリが x64/x86 のみ）
  - free-threaded ビルド（3.13t/3.14t）
  - tkinter が含まれない Python（組み込み版など）

## インストール

1. zip を任意のフォルダーに展開します。
2. **`0_Install.bat`** を実行します。必要なパッケージがインストールされます。
   - 「ViGEm Bus Driver」のセットアップ画面が表示されたら最後まで進めてください。再起動を求められたら再起動します。
   - 画面が表示されず、後でブリッジが「仮想Xboxパッドを作成できません」と表示する場合は、下記から ViGEmBus を手動でインストールしてください。
     https://github.com/nefarius/ViGEmBus/releases

### `0_Install.bat` が行うこと
自分でファイルをダウンロードすることはありません。行うのは次の処理だけです。
- Python がインストールされているか、64ビット版かを確認
- `python -m pip install --upgrade -r requirements.txt` を実行 → PyPI から **pygame-ce 2.5.8** と **vgamepad 0.1.0** の2つのパッケージをインストール

vgamepad パッケージには公式の ViGEmBus 1.17.333 インストーラーが同梱されているため、インストール中にそのセットアップ画面が表示されることがあります。これ以外のドライバーはインストールされません。
- **新規インストール画面**の場合は、Next で最後まで進めてください。
- **「Change / Repair / Remove」（変更／修復／削除）画面**の場合は、ドライバーがすでにインストールされています。**Cancel** を押してください。Remove を選ぶとドライバーが削除されます。

Python 3.14 など新しいバージョンでもインストールできるよう、pygame の代わりに互換版の **pygame-ce** を使います。以前の pygame がある場合、`0_Install.bat` が先に削除します。2つのパッケージは同じフォルダーを使うため、同時にインストールしてはいけません。

### 手動インストール（`0_Install.bat` を使わない場合）
1. 64ビット Python 3.10～3.14 をインストールします（「Add python.exe to PATH」にチェック）。
2. ViGEmBus ドライバーを GitHub から直接インストールします。最新版でも構いません。再起動を求められたら再起動してください。
   https://github.com/nefarius/ViGEmBus/releases
3. 展開したフォルダーでターミナルを開き、次のコマンドを実行します。
   ```
   python -m pip install pygame-ce==2.5.8 vgamepad==0.1.0
   ```
   2でドライバーをインストール済みなのに ViGEmBus のセットアップ画面がまた表示された場合は、キャンセルして構いません。
4. 設定：`python ac8_config.py`（`1_Settings.bat` と同じ）
5. 実行：`python ac8_bridge.py`（`2_Run_Bridge.bat` と同じ）

### アンインストール
- フォルダーを削除します。
- （任意）`python -m pip uninstall pygame-ce vgamepad`
- （任意）Windows の設定 → アプリで「Nefarius Virtual Gamepad Emulation Bus Driver」を削除

## 設定（`1_Settings.bat`）

デバイスをすべて接続してから実行します。

- **ボタンタブ：** 各行の **[割当]** → 使いたい物理ボタンを押すと割り当てられます。行の左のランプは、そのボタンを押すと点灯します。
  - 「加速（ボタン）」「減速（ボタン）」はスロットルが無い場合の項目です。スロットルがある場合は空欄のままにし、スロットルタブで設定してください。
- **飛行軸タブ：** [割当] → 表示された方向に最後まで動かすと、その方向が＋として保存されます。
  - 必須：ロール、ピッチ／任意：ヨー（ツイスト）、スルー（カメラ）
- **スロットルタブ：**
  1. レバーを一番後ろにした状態で [割当] → 一番前まで押します。デュアルレバーは2本それぞれ割り当てると平均値を使います。
  2. キャリブレーション：レバーを最後方／最前方／ニュートラル（巡航速度）に置き、それぞれのボタンを押します。
     - レバー位置に比例して、**後ろ側は LT（減速）、前側は RT（加速）** になります。
     - ニュートラル位置ではゲームの巡航速度が維持されます。
- **ヘッドトラッキング・感度タブ：** 数値を変えて [保存] すると、実行中のブリッジにすぐ反映されます。
- 最後に **[保存]** を押してください。

## 実行

1. （ヘッドトラッキングを使う場合）OpenTrack を起動して **Start** を押します。
2. **`2_Run_Bridge.bat`** を実行します。
3. ブリッジのウィンドウを開いたまま AC8 を起動します。
4. 終了するときは、ブリッジのウィンドウで **Ctrl+C** を押します。仮想パッドを片付けてから終了します。

ブリッジの実行中でも、設定画面で [保存] すると1秒以内に反映されます。

## OpenTrack の設定（ヘッドトラッキング）

- **Output：`freetrack 2.0 Enhanced`**（DCS などで使っているプロファイルをそのまま使えます）
- Input とフィルターは普段どおりで構いません。
- Options → Shortcuts で **Center** キーを設定してください。正面を見て押すと、カメラの基準点が合います。
- ブリッジの表示の最後に `HEAD-ON 角度…` が出れば正常です。`ヘッド無し` の場合は、OpenTrack が Start 状態か、Output が正しいかを確認してください。

## 実デバイスをゲームから隠す（HidHide）

一部のデバイス（例：Thrustmaster TCA Airbus、TWCS）は **AC8 が直接認識** します。するとゲームが実デバイスとブリッジの仮想パッドを同時に読み取り、入力が混ざります。
- 症状の例：スティックを倒すとカメラも動く、スロットルのボタン4を押すとスティックのボタン4の動作も起きる
- 確認方法：**ブリッジを閉じてゲームを起動し、スティックやスロットルを動かしてください。** ゲームが反応すればこのケースです。Steam 入力を無効にしても反応する場合は HidHide が必要です。

HidHide は ViGEmBus と同じ開発者（Nefarius）のツールです。実デバイスをゲームから隠し、ブリッジ（python.exe）にだけ見えるようにします。

1. インストールして再起動：https://github.com/nefarius/HidHide/releases
2. **HidHide Configuration Client** を起動
3. **Applications** タブ → **+** → `python.exe` を追加
   - パスの確認コマンド：`python -c "import sys; print(sys.executable)"`
   - `WindowsApps` フォルダー内の python.exe（Microsoft Store のエイリアス）ではなく、上のコマンドが示す実際のパスを入れてください。
4. **Devices** タブ → 隠すスティックとスロットルにチェック
5. **Enable device hiding** にチェック
6. `1_Settings.bat` を開いてデバイスが表示されるか確認します。「デバイスが見つかりません」と出る場合は、3のパスが間違っています。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 設定画面にデバイスが出ない | `joy.cpl`（Win+R）で認識されているか確認。**HidHide** を使っている場合は、HidHide の Applications に `python.exe` を追加 |
| ブリッジを閉じてもゲームが反応する／入力が混ざる | ゲームが実デバイスを直接読み取っています。上の「実デバイスをゲームから隠す（HidHide）」に従ってください |
| ゲームが HOTAS を無視する | 正常です。ゲームは仮想 Xbox パッドだけを見ています。ブリッジが実行中か確認してください |
| 加速または減速し続ける | スロットルのキャリブレーションをやり直してください |
| ツイストを離してもヨーが入る | 「ヨー作動しきい値」を上げてください |
| ピッチやヨーが逆 | 飛行軸タブで「反転」にチェック |
| カメラが敏感すぎる／鈍い | 「頭の最大角度」を変更してください。小さいほど敏感です |
| 少し頭を動かしても反応せず、急に動く | 「ヘッド アンチデッドゾーン」を少し上げてください（ゲーム側のデッドゾーンの補正） |
| 頭を止めるとカメラが行き過ぎて戻る | 「先行入力」を下げてください |
| ボタンが押されたままになる | トグルスイッチ（位置が固定されるスイッチ）を割り当てていないか確認。ランプが点きっぱなしなら別のボタンに変えてください |

## 注意

- 外部コントローラーエミュレーションはご自身の判断で使用してください。ゲームファイルに触れない外部方式ですが、ゲームのアンチチートの方針が今後変わる可能性までは保証できません。
- ViGEmBus は開発が終了したドライバーです。現在の Windows 10/11 では正常に動作します。
- 同じモデルのデバイス2台（例：同じスティック2本）は区別できない場合があります。
