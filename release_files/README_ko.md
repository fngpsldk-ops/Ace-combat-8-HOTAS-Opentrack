# AC8 HOTAS 브리지 (헤드트래킹 지원) v1.03

ACE COMBAT 8에서 **HOTAS(비행 스틱·스로틀)**와 **OpenTrack 헤드트래킹**을 쓸 수 있게 해 주는 도구입니다.

AC8은 Xbox 패드만 제대로 인식합니다. 이 도구는 스틱·스로틀 입력을 읽어 **가상 Xbox 360 패드**로 바꿔 줍니다.
게임 파일을 수정하거나 게임에 코드를 주입하지 않습니다.

```
스틱 + 스로틀 ─┐
               ├→ 브리지 → 가상 Xbox 360 패드 → AC8
OpenTrack ─────┘   (헤드트래킹 → 오른쪽 스틱 = 카메라)
```

- DirectInput 방식의 스틱/스로틀/페달이면 제조사와 상관없이 사용 가능 (VKB, Virpil, Thrustmaster, Logitech 등)
- 스로틀이 없어도 사용 가능 (가속/감속을 버튼에 지정)
- 설정 창: 한국어 / English / 日本語

## 필요한 것

| 항목 | 필수 | 비고 |
|---|---|---|
| Windows 10/11 | 필수 | |
| 64비트 Python 3.10~3.14 | 필수 | 설치할 때 **"Add python.exe to PATH" 체크** |
| ViGEmBus 드라이버 | 필수 | `0_Install.bat`을 실행하면 설치 창이 뜸 |
| OpenTrack | 선택 | 헤드트래킹을 쓸 때만 |
| HidHide | 장비에 따라 | 브리지를 꺼도 게임이 스틱에 반응하는 장비일 때 필요 (아래 "실제 장비를 게임에서 숨기기" 참고) |

**Python 호환성**
- 동작 확인: Python 3.10, 3.14 (python.org 공식 64비트 설치판)
- 3.11~3.13, 3.15: 필요한 패키지가 지원하므로 동작할 것으로 예상됩니다(직접 확인은 안 함).
- 지원 안 됨:
  - Python 3.9 이하
  - 32비트 Python
  - ARM64 Windows용 Python (가상 패드 라이브러리가 x64/x86용뿐)
  - free-threaded 빌드(3.13t/3.14t)
  - tkinter가 빠진 Python(임베디드판 등)

## 설치

1. 압축을 원하는 폴더에 풉니다.
2. **`0_Install.bat`** 실행 → 필요한 패키지가 설치됩니다.
   - "ViGEm Bus Driver" 설치 창이 뜨면 끝까지 진행하세요. 재부팅을 요청하면 재부팅합니다.
   - 창이 뜨지 않았는데 나중에 브리지가 "가상 Xbox 패드를 만들 수 없습니다"라고 하면, 아래에서 ViGEmBus를 직접 설치하세요.
     https://github.com/nefarius/ViGEmBus/releases

### `0_Install.bat`이 하는 일
직접 내려받는 파일은 없습니다. 하는 일은 다음뿐입니다.
- Python이 설치되어 있는지, 64비트인지 확인
- `python -m pip install --upgrade -r requirements.txt` 실행 → PyPI에서 **pygame-ce 2.5.8**, **vgamepad 0.1.0** 두 패키지 설치

vgamepad 패키지에는 공식 ViGEmBus 1.17.333 설치 파일이 들어 있어서, 설치 중에 그 설치 창이 뜰 수 있습니다. 이 외에 설치되는 드라이버는 없습니다.
- **새 설치 화면**이면 Next로 끝까지 진행하세요.
- **"Change / Repair / Remove"(변경/복구/제거) 화면**이면 드라이버가 이미 설치된 것입니다. **Cancel**을 누르세요. Remove를 고르면 드라이버가 지워집니다.

Python 3.14 등 최신 버전에서도 설치되도록 pygame 대신 호환판인 **pygame-ce**를 씁니다. 예전에 설치한 pygame이 있으면 `0_Install.bat`이 먼저 제거합니다. 두 패키지는 같은 폴더를 쓰기 때문에 함께 설치하면 안 됩니다.

### 수동 설치 (`0_Install.bat`을 쓰지 않을 때)
1. 64비트 Python 3.10~3.14 설치 ("Add python.exe to PATH" 체크)
2. ViGEmBus 드라이버를 GitHub에서 직접 설치합니다. 최신 버전도 됩니다. 재부팅을 요청하면 재부팅하세요.
   https://github.com/nefarius/ViGEmBus/releases
3. 압축을 푼 폴더에서 터미널을 열고 아래 명령을 실행합니다.
   ```
   python -m pip install pygame-ce==2.5.8 vgamepad==0.1.0
   ```
   2번에서 드라이버를 이미 설치했는데 ViGEmBus 설치 창이 또 뜨면 취소해도 됩니다.
4. 설정: `python ac8_config.py` (`1_Settings.bat`과 같음)
5. 실행: `python ac8_bridge.py` (`2_Run_Bridge.bat`과 같음)

### 제거
- 폴더를 삭제합니다.
- (선택) `python -m pip uninstall pygame-ce vgamepad`
- (선택) Windows 설정 → 앱에서 "Nefarius Virtual Gamepad Emulation Bus Driver" 제거

## 설정 (`1_Settings.bat`)

장비를 모두 연결한 뒤 실행합니다.

- **버튼 탭:** 각 줄의 **[입력]** → 쓰고 싶은 물리 버튼을 누르면 지정됩니다. 줄 왼쪽의 표시등은 그 버튼을 누르면 켜집니다.
  - "가속 (버튼)", "감속 (버튼)"은 스로틀이 없을 때 쓰는 항목입니다. 스로틀이 있으면 비워 두고 스로틀 탭에서 설정하세요.
- **비행 축 탭:** [입력] → 안내된 방향으로 끝까지 움직이면, 그 방향이 +로 저장됩니다.
  - 필수: 롤, 피치 / 선택: 요(트위스트), 슬루(카메라)
- **스로틀 탭:**
  1. 레버를 맨 뒤에 둔 채 [입력] → 앞으로 끝까지 밉니다. 듀얼 레버면 두 개를 각각 지정하고, 평균값이 쓰입니다.
  2. 보정: 레버를 맨 뒤/맨 앞/중립(순항 속도)에 두고 각 버튼을 누릅니다.
     - 레버 위치에 비례해서 **뒤쪽은 LT(감속), 앞쪽은 RT(가속)**가 됩니다.
     - 중립 위치에서는 게임의 순항 속도가 유지됩니다.
- **헤드트래킹·감도 탭:** 숫자를 바꾸고 [저장]하면 실행 중인 브리지에 바로 반영됩니다.
  - 롤/피치 반응: **감도 배율**(클수록 덜 젖혀도 최대), **커브**(1보다 작으면 중앙이 예민), **안티 데드존**(게임 데드존 건너뛰기)
- 마지막에 **[저장]**을 누르세요.

## 실행

1. (헤드트래킹을 쓸 때) OpenTrack을 켜고 **Start**를 누릅니다.
2. **`2_Run_Bridge.bat`** 실행
3. 브리지 창을 켜 둔 채로 AC8을 실행합니다.
4. 끝나면 브리지 창에서 **Ctrl+C**로 종료합니다. 가상 패드를 정리하고 끝납니다.

브리지 실행 중에도 설정 창에서 [저장]하면 1초 안에 반영됩니다.

## OpenTrack 설정 (헤드트래킹)

- **Output: `freetrack 2.0 Enhanced`** (DCS 등에서 쓰는 설정 그대로 사용 가능)
- Input과 필터는 평소대로 쓰시면 됩니다.
- Options → Shortcuts에서 **Center** 키를 지정해 두세요. 정면을 보고 누르면 카메라 기준점이 맞춰집니다.
- 브리지 창 끝에 `HEAD-ON 각도…`가 표시되면 정상입니다. `헤드없음`이면 OpenTrack이 Start 상태인지, Output이 맞는지 확인하세요.

## 실제 장비를 게임에서 숨기기 (HidHide)

일부 장비(예: Thrustmaster TCA Airbus, TWCS)는 **AC8이 직접 인식**합니다. 그러면 게임이 실제 장비와 브리지의 가상 패드를 동시에 읽어서 입력이 섞입니다.
- 증상 예: 스틱을 기울이면 카메라도 움직임, 스로틀 버튼 4를 누르면 스틱 버튼 4 동작도 같이 됨
- 확인: **브리지를 끄고 게임을 켰을 때 스틱이나 스로틀에 반응하면** 이 경우입니다. Steam 입력을 꺼도 반응한다면 HidHide가 필요합니다.

HidHide는 ViGEmBus와 같은 개발자(Nefarius)가 만든 도구입니다. 게임에는 실제 장비를 숨기고, 브리지(python.exe)에게만 보이게 합니다.

1. 설치 후 재부팅: https://github.com/nefarius/HidHide/releases
2. **HidHide Configuration Client** 실행
3. **Applications** 탭 → **+** → `python.exe` 추가
   - 경로 확인 명령: `python -c "import sys; print(sys.executable)"`
   - `WindowsApps` 폴더 안의 python.exe(Microsoft Store 바로가기)가 아니라, 위 명령이 알려 주는 실제 경로를 넣으세요.
4. **Devices** 탭 → 숨길 스틱과 스로틀 체크
5. **Enable device hiding** 체크
6. `1_Settings.bat`을 열어 장비가 보이는지 확인합니다. "인식된 장비가 없습니다"가 나오면 3번 경로가 틀린 것입니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 설정 창에 장비가 안 보임 | `joy.cpl`(Win+R)에서 보이는지 확인. **HidHide**를 쓰고 있다면 HidHide 설정의 Applications에 `python.exe`를 추가 |
| 브리지를 꺼도 게임이 반응함 / 입력이 섞임 | 게임이 실제 장비를 직접 읽는 경우입니다. 위의 "실제 장비를 게임에서 숨기기 (HidHide)"를 따르세요 |
| 게임이 HOTAS를 무시함 | 정상입니다. 게임은 가상 Xbox 패드만 봅니다. 브리지가 실행 중인지 확인 |
| 계속 가속하거나 감속함 | 스로틀 탭에서 보정을 다시 하세요 |
| 트위스트를 놓아도 요가 들어감 | 감도 탭에서 "요 작동 기준"을 올리세요 |
| 피치나 요가 반대 | 비행 축 탭에서 "반전" 체크 |
| 비행 조작이 둔하게 느껴짐 | 감도 탭에서 "롤/피치 감도 배율" 1.2~1.3, "커브" 0.8, "안티 데드존" 0.1부터 하나씩 바꿔 보세요 |
| 카메라가 너무 민감하거나 둔함 | "헤드 최대 각도"를 바꾸세요. 작을수록 민감합니다 |
| 고개를 살짝 돌리면 반응이 없다가 갑자기 움직임 | "헤드 안티 데드존"을 조금 올리세요 (게임 자체 데드존 보정) |
| 고개를 멈추면 카메라가 넘어갔다 돌아옴 | "선행 입력"을 낮추세요 |
| 버튼이 계속 눌린 상태 | 토글 스위치(위치가 고정되는 스위치)를 지정했는지 확인. 표시등이 계속 켜져 있으면 다른 버튼으로 바꾸세요 |

## 주의

- 외부 컨트롤러 에뮬레이션은 본인 판단으로 사용하세요. 게임 파일을 건드리지 않는 외부 방식이지만, 게임의 안티치트 정책이 바뀔 가능성까지 보장하지는 않습니다.
- ViGEmBus는 개발이 종료된 드라이버입니다. 현재 Windows 10/11에서는 정상 동작합니다.
- 같은 모델의 장비 2개(예: 동일한 스틱 2개)는 구분되지 않을 수 있습니다.
